# The design skills drive Phase 5, they do not review it

Owner instruction, verbatim: *"the design skills should be used in the design of the website for the
next phase."*

Read as: the taste skills are an **input to** Phase 5's design work, not a checklist run over
something already built. Phase 5 already lists "Full pre-flight matrix from the design-taste skill
(DSG-08)" as a done-when item, and that is the audit half. This todo is the other half, and it has
to happen first, at `/gsd-ui-phase 5` time when `UI-SPEC.md` is being written.

Available and relevant:

- **`design-taste`** — the broad one: typography, colour, spacing, hierarchy, motion,
  micro-interactions, component states, responsive behaviour, anti-pattern detection.
- **`design-taste-frontend`** — the anti-slop build skill, audit-first on redesigns, which is what
  the album is.
- **`redesign-existing-projects`** — upgrades an existing site without breaking it. Directly
  applicable: Phase 5 is a redesign pass over four shipped phases, not a greenfield build.
- **`high-end-visual-design`** — the specifics that make a page feel expensive rather than
  templated.

The house style is already strong and opinionated (the writing especially), so the risk is not
blandness, it is a redesign that fights the voice. Anything the skills propose has to survive the
existing register: the copy is jokes and sentences, not fields.

Concrete first target is the album, per [[album-split-and-redesign]].
