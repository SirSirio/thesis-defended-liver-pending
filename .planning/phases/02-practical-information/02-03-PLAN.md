<objective>
Build the access section's text half: the written directions that carry the section on bad
signal (D-12), and the practical notes that answer the questions guests actually send messages
about (D-16, D-17). Both render from JS into `#access-body` through `renderAccess()`, both
degrade deliberately when unconfigured (D-18, D-19), and both sit above the video because text
is read faster than video loads (D-15).

Purpose: the venue is a 76 unit kollegium with multiple entrances (D-02). "Which door" is not a
joke here, it is the actual navigation problem the site exists to solve, and a guest standing
outside in October reads a numbered list faster than anything else on the page.

Output: `renderAccess()` in the language chain, a written directions block that accepts a
sentence or a list of steps, and a notes definition list that echoes the course fact table.
</objective>

## Resolved assumption transition

**ROADMAP Phase 2 describes "written fallback directions". CONTEXT.md D-12 promotes them to
always visible, positioned above the video, never merely a fallback.** D-12 wins and this is
already decided; it is not reopened here. The roadmap wording was superseded deliberately, not
misread. A guest outdoors on bad signal reads text faster than a video loads, and the text still
works when the video does not, which is a stronger reading of ACC-04 than "accompanies".

## Resolved contradiction between two source documents

The resolved-edge line for ACC-04 states that with `door.directions` null "the directions
sub-heading and its container are both absent", while 02-UI-SPEC.md section 9 states that null
renders a `.pending` block with the `access.dir.pending.*` copy. Taken literally these disagree.

**Resolution, and it satisfies both:** when `door.directions` is null, render the `.pending`
panel and omit the `access.dir.heading` sub-heading entirely. The panel's own `.pending__t`
title, "Door instructions pending", is the heading. The forbidden state that the edge names, a
heading standing over nothing, never occurs, and the UI contract's pending panel still ships.
Recorded here so the reconciliation is visible rather than silently chosen.
