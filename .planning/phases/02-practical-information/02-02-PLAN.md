<objective>
Mount the interactive map the owner asked for alongside the directions buttons, without
letting Google anywhere near first paint. The embed is keyless (D-07), the frame is never in
the static markup (D-08), it mounts on approach through IntersectionObserver, and the slot is
a fixed ratio box with three deliberate states (D-09). Both affordances ship and neither
replaces the other (D-04).

Purpose: the owner explicitly wanted both a handoff to the native map app and an interactive
map on the page. LOC-04 exists because this section is read outdoors on mobile data, so the
map must cost nothing until it is nearly on screen, and must never make the address wait.

Output: `#loc-map`, a slot created once and never rebuilt, holding a styled waiting layer that
becomes a live map, or a message that names what still works when the embed is blocked. Motion
is restrained to a loader bar and one opacity crossfade, each with its reduced-motion fallback
in this phase (D-21, D-22).
</objective>
